# 校园失物招领

2026 秋软件工程第二次结对作业。

## 项目简介

校园失物招领 Web 应用，支持发布、浏览、搜索、查看详情、联系发布者、修改状态。

## 目录结构

- index.html：首页
- publish.html：发布页
- search.html：搜索页
- detail.html：详情页
- mine.html：我的发布
- css/style.css：样式
- js/data.js：数据层
- js/home.js：首页逻辑
- js/publish.js：发布页逻辑
- js/search.js：搜索页逻辑
- js/detail.js：详情页逻辑
- js/mine.js：我的发布逻辑
- README.md：本文件

## 使用说明

1. 用 Chrome 打开 index.html 即可运行。
2. 或者用 VS Code 的 Live Server 打开。
3. 数据存在浏览器 localStorage 中，首次打开自动初始化 7 条种子数据。

## 技术说明

纯前端实现：HTML + CSS + 原生 JavaScript，无第三方框架。
